با توجه به وجود ضوابط متعدد و حتی پراکنده برای محاسبه تغییر مقادیر کار در پیمان‌ها، بسیاری از کارشناسان این محاسبات را چالش‌برانگیز فرض نموده و حتی تفسیرهای متفاوتی از ضوابط فراوان آن ارایه می‌دهند. در این راستا و برای رفع ریشه‌ای مشکل، برنامه‌ای طراحی شده که به‌سادگی این محاسبات را انجام داده و نتیجه‌ی صحت تغییرات پیمان را اعلام می‌کند.
